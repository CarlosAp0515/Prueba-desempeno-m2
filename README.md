# 🎸 Landing Page – Rock Band (HTML & CSS Assessment)

## 📌 Project Overview

This project is a **starter template** for a performance assessment focused on building a responsive landing page for a rock band.

The goal is to transform this base into a **visually engaging, responsive, and well-structured website** that promotes the band, their identity, and upcoming events.
## Technologies Used

* HTML5 (Semantic structure)
* CSS3 (Flexbox, Grid, Responsive Design)

---

##  Project Structure

* **Header**: Navigation bar and band rock logo
* **Hero Section**: Main call-to-action with a buy button
* **Events Section**: Schedule of tastings using an HTML table
* **About Section**: Information about the band rock and its philosophy
* **Multimedia Section**: concerts and  video concerts
* **our members Section**: some of the our members band
* **Footer**: Contact information and social media links

---

## Responsive Design

The website is fully responsive and adapts to:

* Desktop (>1024px)
* Tablet (≤1024px)
* Mobile (≤768px)

Media queries were used to ensure a proper layout across all devices.

---

##  How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Open the `index.html` file in your browser

---

##  Extra Features

* Styled HTML table with `<thead>`, `<tbody>`, and `<tfoot>`
* CSS hover effects and subtle animations
